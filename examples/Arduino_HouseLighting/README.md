# Подсветка дома по 4 углам (закат/рассвет, диммирование, телефон/ПК)

Система — **4 независимых устройства** LilyGo T-Call SIM800 (по одному на каждый угол дома),
на каждом **8 диммируемых каналов**. Все устройства прошиваются одним скетчем,
отличается только номер устройства `DEVICE_ID` (1…4).

Каждое устройство работает автономно:

- само считает время восхода и заката по координатам (интернет для этого не нужен);
- включает свет на закате, выключает на рассвете (смещения ± минуты);
- ночной режим: после заданного часа (например, 23:00) яркость снижается до N % или свет выключается;
- плавное включение/выключение (2 с) с гамма-коррекцией: 10 % на ползунке выглядит как 10 %;
- у каждого канала своё имя, вечерняя яркость и признак «в расписании / только вручную»;
- настройки и ручной режим сохраняются во флеш и восстанавливаются после пропадания питания.

Управление:

- **с телефона или компьютера** — веб-страница устройства `http://houselight-N.local` или по IP.
  На странице любого устройства есть **общая панель всех 4 углов** и кнопки «Весь дом»;
- **по SMS** через SIM800 (если вставлена SIM-карта) — работает даже без Wi-Fi и интернета.

Источник времени (по приоритету): NTP по Wi-Fi → время сотовой сети от SIM800 →
кнопка «Время с этого телефона/ПК» в веб-интерфейсе.

## Почему PCA9685

Свободных GPIO на T-Call мало: модем, контроллер питания, PSRAM (WROVER) и
загрузочные (strapping) пины занимают почти всё. Восемь чистых ШИМ-выходов без
риска «мигнуть» светом при загрузке не получить. Поэтому на каждом устройстве
стоит модуль **PCA9685** (16 каналов, 12 бит ШИМ, I2C). Он подключается к той же
шине I2C, что и микросхема питания платы. Свободно ещё 8 каналов (до 16 через `NCH`).

## Подключение (на каждом из 4 устройств)

```
 T-Call                PCA9685                 MOSFET-модуль (×8)        Нагрузка
 3V3  ───────────────  VCC
 GND  ───────────────  GND  ──────────────────  GND (общий с БП 12/24 В)
 IO21 (SDA) ─────────  SDA
 IO22 (SCL) ─────────  SCL
                       OE   ── GND
                       PWM0 ──────────────────  IN / SIG   ── OUT- ──  LED-лента 12/24 В (канал 1)
                       ...                                             ...
                       PWM7 ──────────────────  IN / SIG   ── OUT- ──  LED-лента 12/24 В (канал 8)
                                                              БП +12/24 В ── LED+
```

- PCA9685 питайте от 3.3 В платы, клемма V+ (питание сервоприводов) не нужна.
- MOSFET — только **logic-level** (IRLZ44N, IRLR7843, AOD4184 и т.п.) или готовые
  модули на них. Резистор 10 кОм затвор→GND на каждом канале не помешает.
- Провода I2C — короткие (до 20-30 см), PCA9685 ставьте рядом с платой.
- **Лампы 220 В** ШИМ-ом напрямую не диммируются. Нужен LED-драйвер с входом
  диммирования PWM или 0/1-10 В (например, Mean Well серии с суффиксом «B»/«P»),
  либо диммируемые 12/24 В светильники через MOSFET, как на схеме.
- Если драйвер включается низким уровнем, поставьте `PWM_INVERT 1`.

### Питание платы

Удобно взять один БП 12/24 В на угол и понижающий преобразователь на 5 В для T-Call.

- **Версии с IP5306**: пин 5V на плате — это **выход**. Питание 5 В подавайте через USB-C
  (или аккумулятор).
- **Версии с AXP192**: пин 5V — вход, можно подключать напрямую.

Аккумулятор 18650 в держателе платы работает как ИБП: при пропадании сети устройство
останется на связи по SMS.

## Прошивка

1. Arduino IDE, плата **ESP32 Dev Module** (или ESP32 Wrover Module), ядро esp32 2.x или 3.x.
2. В начале `Arduino_HouseLighting.ino` выберите свою плату (`SIM800L_IP5306_VERSION_20200811` и т.п.)
   и **номер устройства** `#define DEVICE_ID 1` (для каждого угла свой: 1, 2, 3, 4).
3. Для версий с AXP192 нужна библиотека [AXP202X_Library](https://github.com/lewisxhe/AXP202X_Library).
   Других внешних библиотек нет.
4. Без SIM-карты/модема поставьте `#define USE_MODEM 0`.

## Первая настройка

1. После прошивки устройство поднимает Wi-Fi точку **`HouseLight-N-Setup`**, пароль `12345678`.
   Подключитесь к ней и откройте `http://192.168.4.1`.
2. «Настройки этого устройства» → Wi-Fi: введите домашнюю сеть и сохраните (устройство перезагрузится).
3. Откройте `http://houselight-N.local` (или IP из роутера/монитора порта) и заполните:
   - **координаты** дома (широта/долгота из Google/Яндекс Карт) и **часовой пояс**: список подсказок
     есть в поле, формат POSIX TZ — `MSK-3`, `EET-2EEST,M3.5.0/3,M10.5.0/4`, `<+05>-5` …;
   - смещения закат/рассвет, ночной режим;
   - имена каналов («Фасад», «Окна», «Карниз»…), вечернюю яркость, участие в расписании;
   - **адреса трёх соседних устройств** — тогда на этой странице будут видны и управляться все 4 угла.
     Лучше закрепить IP в роутере (DHCP-резервирование) и писать IP: `.local` работает не на всех Android;
   - логин/пароль на веб (рекомендуется). Если пароль задан, задайте **одинаковый** на всех 4 устройствах
     и впишите его в поле «Логин:пароль соседей» (`admin:пароль`). Оно хранится только в браузере;
   - номер телефона для SMS-команд.
4. Повторите для остальных трёх устройств (или настройте одно, а остальным задайте только Wi-Fi и номер).

Совет: на телефоне добавьте страницу на главный экран (браузер → «На главный экран»). Получится как приложение.

## Как работает расписание

| Режим | Поведение |
|---|---|
| **Авто** | Включение в `закат + смещение`, выключение в `рассвет + смещение`. Ползунок канала задаёт яркость **до ближайшего заката/рассвета**, потом канал снова идёт по расписанию (кнопка «А» возвращает сразу). |
| **Ночь** (опционально) | С заданного часа до рассвета яркость = вечерняя × `ночной %` (0 % — выключить). |
| **Ручной** | Расписание игнорируется, каналы держат выставленную яркость и после перезагрузки. |

Для полярного дня или ночи учтено: свет не горит весь день или горит всю ночь соответственно.

## SMS-команды

Принимаются только с номера, указанного в настройках. Сравниваются последние 9 цифр,
так что `+7…`, `8…`, `+380…` совпадут. Ответ приходит SMS со статусом.
Каждое устройство управляется своей SIM-картой (команда относится к тому углу, на чью SIM отправлена).

| Команда | Действие |
|---|---|
| `STATUS` или `?` | статус: режим, время включения/выключения, яркость каналов |
| `ON` / `ON 50` | все каналы на 100 % / 50 % |
| `OFF` | все каналы выключить |
| `AUTO` | режим «Авто», сбросить ручные корректировки |
| `MANUAL` | ручной режим |
| `C3 70`, `C3 ON`, `C3 OFF`, `C3 AUTO` | канал 3: яркость / вкл / выкл / вернуть в расписание |

## HTTP API (для своих интеграций: Home Assistant, Node-RED, скрипты)

| Метод | URL | Параметры |
|---|---|---|
| GET | `/api/state` | текущее состояние (JSON) |
| POST | `/api/corner` | `i=0..7&level=0..100` или `i=0..7&auto=1` |
| POST | `/api/all` | `level=0..100` или `auto=1` |
| POST | `/api/mode` | `mode=auto` / `mode=manual` |
| GET/POST | `/api/config` | настройки (поля как в форме) |
| POST | `/api/time` | `epoch=<unix time>` |

Пример: `curl -u admin:пароль -d "level=30" http://houselight-2.local/api/all`

## Доступ из интернета

Веб-интерфейс рассчитан на домашнюю сеть. Издалека проще всего управлять по SMS.
Для доступа через интернет используйте VPN до домашнего роутера (WireGuard, Tailscale на роутере/NAS).
Пробрасывать порт 80 устройства в интернет напрямую не стоит: там нет HTTPS.

## Параметры в начале скетча

| Параметр | По умолчанию | Описание |
|---|---|---|
| `DEVICE_ID` | 1 | номер устройства/угла, задаёт имя `houselight-N` |
| `USE_MODEM` | 1 | SIM800: SMS и время сети |
| `NCH` | 8 | каналов на устройство (до 16) |
| `PCA9685_ADDR` | 0x40 | I2C-адрес PCA9685 |
| `PWM_FREQ` | 1000 | частота ШИМ, Гц |
| `PWM_INVERT` | 0 | инверсия выхода |
| `FADE_MS` | 2000 | время плавного перехода 0→100 % |
